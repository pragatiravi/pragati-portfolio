## 🌟 Overview

This repository hosts the personal portfolio website of **Pragati Ravi Gangoji**, a Python-focused Software Developer with expertise in scalable backend architectures, full-stack web applications, AI/ML integrations, and cloud infrastructure.

Designed with a sleek dark-mode glassmorphic theme, smooth micro-interactions, responsive layouts, and accessible motion controls.

---

## ✨ Features

- **🎨 Modern Dark Aesthetics**: Deep neon glow palette (`#0a0a0f`, violet, and cyan accents) with polished glassmorphic surfaces.
- **🚀 Ultra Fast**: Powered by Vite and React 18 for instant Hot Module Replacement (HMR) and optimized production bundles.
- **📱 Fully Responsive**: Pixel-perfect layout across mobile, tablet, and desktop screens.
- **🎬 Interactive Animations**: Spring-based scroll progress bar, staggered reveal animations, hover tilt effects, and modal transitions powered by Framer Motion.
- **♿ Motion-Safe**: Honors `prefers-reduced-motion` user preferences for accessibility.
- **💼 Interactive Project Showcase**: Filter projects by categories (*AI & ML*, *Full-Stack*, *Security*) with deep-dive modal dialogs displaying tech stacks, impact metrics, and repository links.
- **📊 Dynamic Stats & Timeline**: Animated counting metrics, categorized technical skills, services, session records, and career experience timeline.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.0 or higher) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pragatiravi/pragati-portfolio.git
   cd pragati-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

4. **Create a production build:**
   ```bash
   npm run build
   ```
   The optimized production bundle will be output to the `dist/` directory.

5. **Preview the production build locally:**
   ```bash
   npm run preview
   ```

## 🌐 Deployment

### Deploying to Vercel

1. Push your latest code to GitHub.
2. Sign in to [Vercel](https://vercel.com) and click **"Add New"** > **"Project"**.
3. Import the `pragati-portfolio` repository.
4. Set the build settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**.

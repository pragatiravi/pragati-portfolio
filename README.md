# Pragati Ravi Gangoji – Portfolio
React + Vite + Tailwind 4 + Framer Motion.
## Run
`npm install && npm run dev` · build: `npm run build`
## Deploy (Vercel)
Push to GitHub → vercel.com → Import repo → Framework: Vite (build `npm run build`, output `dist`) → Deploy.
